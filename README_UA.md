# Сайт Юлії Широкун — інструкція з редагування

## Що всередині
- `index.html` — головна сторінка українською.
- `style.css` — кольори, шрифти, відступи та адаптивність.
- `script.js` — мобільне меню та автоматичний рік у футері.
- `en/index.html` — англійська версія.
- `payment/index.html` — сторінка оплати-заглушка.
- `documents/` — чотири шаблони документів.
- `assets/images/` — фотографії.
- `assets/icons/` — favicon.

## Як додати фотографію
1. Підготуйте портретне фото у форматі JPG або WebP.
2. Завантажте його до `assets/images/` з назвою `portrait.jpg`.
3. У `index.html` знайдіть `portrait-placeholder.svg` та замініть на `portrait.jpg`.
4. Те саме зробіть в `en/index.html`, де шлях починається з `../assets/images/`.

## Як додати контакти
У `index.html` знайдіть коментарі `ЗАМІНИТИ` біля кнопок Telegram та Instagram.
- Telegram: вставте адресу профілю, наприклад `https://t.me/your_username`.
- Instagram: вставте адресу профілю, наприклад `https://instagram.com/your_profile`.
- Телефон: замініть `+380000000000` у `href="tel:..."` і текст-заглушку на реальний номер.
Повторіть для `en/index.html`.

## Як змінювати тексти
Відкрийте `index.html` і замініть текст у відповідних блоках. Коментарі `ЗАМІНИТИ` підказують, що саме потрібно змінити. Англійські тексти редагуються окремо у `en/index.html`.

## Як змінити кольори
На початку `style.css` є змінні:
- `--purple: #2c1e45`
- `--lavender: #9d84c9`
- `--cream: #f4efe7`
- `--ink: #35313a`

Змінюйте значення після двокрапки.

## Сторінка оплати
Адреса після публікації: `https://psyinua.github.io/payment/`
- Для IBAN додайте реквізити та за потреби кнопку копіювання.
- Для LiqPay додайте готове платіжне посилання, створене в кабінеті LiqPay.
- Не вставляйте секретні ключі LiqPay у HTML або JavaScript. Статичний GitHub Pages не може безпечно створювати підписані платежі чи перевіряти їх статус.

## Юридичні документи
Шаблони розміщені в `documents/`. Вони навмисно містять підказки, а не юридично готові формулювання. Заповніть їх за реальними процесами практики та перевірте з юристом перед публікацією.

Адреси:
- `/documents/offer.html`
- `/documents/privacy.html`
- `/documents/personal-data.html`
- `/documents/consent.html`

## Публікація на GitHub Pages
1. У профілі `psyinua` створіть репозиторій з точною назвою `psyinua.github.io`.
2. Завантажте вміст цієї папки в корінь репозиторію (не саму папку `psyinua-site`).
3. У репозиторії відкрийте **Settings → Pages**.
4. У **Build and deployment** оберіть **Deploy from a branch**.
5. Branch: `main`; folder: `/ (root)`; натисніть **Save**.
6. Через кілька хвилин сайт має бути доступний за адресою `https://psyinua.github.io/`.

## Важливі примітки
- GitHub Pages підтримує HTML, CSS та JavaScript у браузері, але не запускає серверний код і базу даних.
- Сторінки оплати та документів позначені `noindex`; це не є паролем і не обмежує доступ за посиланням.
- Сторінки UA/EN мають окремий вміст. Оновлюйте їх обидві.
- Google Fonts завантажуються ззовні. Якщо потрібна робота без зовнішніх залежностей, можна пізніше додати локальні файли шрифтів (перевіривши ліцензії).
